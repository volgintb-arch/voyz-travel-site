# VOYZ Travel — сайт туров по Кыргызстану на внедорожниках

Статический сайт (HTML/CSS/JS), без сборки на сервере. 7 маршрутов на весь год, календарь сезонов,
фильтр в каталоге, форма заявки. Два языка: русский (`/`) и английский (`/en/`). Предпросмотр закрыт от поисковиков (`noindex`).

## Статус контента
- **Grand Expedition** — реальный маршрут VOYZ (по утверждённой программе).
- **Остальные 6 туров — концепты** (`data/tours_extra.json`, флаг `"concept": true`): маршруты придуманы на реальной
  географии Кыргызстана по образцу предложений конкурентов. Цены, даты, отзывы и контакты не придуманы.
  Перед запуском их нужно проверить: дороги и сезоны, разрешения для приграничных зон, ночёвки, безопасность.
- Для зимнего и весеннего туров на бесплатных стоках нет подходящих фото: использованы спутниковый снимок
  Copernicus и нейтральные кадры (см. `photo_note`). Нужны реальные сезонные фото.

## Адаптация по экранам
- **Компьютер (шире 1024 px)** — обычный сайт на всю ширину экрана: до 1600 px вёрстка растягивается, дальше вся страница пропорционально масштабируется (`assets/scale.js`), поэтому на 2K и 4K композиция та же, только крупнее.
- **Планшет и телефон (до 1024 px)** — тот же сайт в виде приложения (`app/`, стиль iOS: «жидкое стекло», вкладки, крупные заголовки, шторка заявки). Сайт сам перенаправляет на `app/`; ссылка «Полная версия сайта» отключает переход. Это страница сайта, а не установленное приложение.
- `app/` собирается командой `python build_app.py` из тех же данных (после `build_site.py`). Если открыть `app/` на компьютере, он вернёт на сайт; для просмотра в рамке телефона добавьте `?preview`.

## Видео и анимации
- Видео из ваших стоков Pexels (`assets/video/`: 7 клипов, 720p, без звука, 6,4 МБ вместе, с постерами). Играют в шапках главной и нескольких туров и в ленте «В движении»; в режиме «уменьшить движение» отключаются.
- Движение: появление слов в заголовке, бегущая строка, счётчики, параллакс фото, прорисовка маршрута на карте, заполнение календаря, индикатор прокрутки.
- Секции чередуют светлый, белый и тёмный фон (классы `.light`, `.white`, по умолчанию тёмный), одинаковые не стоят рядом; вертикальные отступы заданы одной переменной `.sec`. Лайм только акцент: кнопки, метки, полосы календаря.

## Языки и SEO (Европа, Азия, Кыргызстан)
- Английская версия собирается из русской словарём `data/en.json` (`python build_site.py` печатает/сохраняет непереведённые строки в `data/en_missing.json`). Перевод сделан автоматически, его стоит вычитать носителю языка.
- На каждой странице: `title`, `description`, canonical, `hreflang` ru / en / x-default, Open Graph и Twitter Card (картинки 1200×630 в `assets/og/`, пересборка `python make_og.py`), JSON-LD (TravelAgency, WebSite, BreadcrumbList, ItemList, TouristTrip, FAQPage), `sitemap.xml` с альтернативами языков, `robots.txt`, `site.webmanifest`, `404.html`.
- Фавикон: `favicon.ico`, `favicon.svg`, `assets/icons/*` (пересборка `python make_icons.py`).
- Коды подтверждения Google / Яндекс / Bing: словарь `VERIFY` в `build_site.py`.
- Приложение: `app/` (RU) и `en/app/` (EN), `python build_app.py`. Поисковые и превью-боты на приложение не перенаправляются.
- Проверка всего сразу: `python -m http.server 8765` и `python test_all.py`.

## Перед запуском
1. `assets/config.js` — куда отправлять заявки (`formEndpoint`: Formspree, вебхук Make/Zapier, свой бэкенд) и контакты
   (`telegram`, `whatsapp`, `phone`, `email`). Пустые значения скрыты, ничего не выдумано.
2. `privacy/` — политика конфиденциальности: краткая редакция, согласовать с юристом.
3. Цены: поле `price` в данных тура (сейчас `null`, цена не показывается).
4. В `build_site.py` указать настоящий адрес в `SITE_URL` (например `https://voyz.ru`), переключить `INDEXABLE = True`, вставить коды в `VERIFY`, заново выполнить `build_site.py`, `build_app.py` и отправить `sitemap.xml` в Google Search Console, Яндекс Вебмастер и Bing Webmaster.
5. Права на фото Кок-Мойнока и Ак-Сай (из архива VOYZ) подтвердить. Авторы остальных фото: страница `credits/`
   (лицензии CC BY / CC BY-SA требуют указания авторства).

## Как добавить или изменить тур
Данные лежат в `data/tours.json` (флагман) и `data/tours_extra.json` (остальные туры). После правки:

```bash
python build_site.py
```

Скрипт пересоберёт все страницы (`index.html`, `tours/…`). Нужен Python 3 без внешних библиотек.
