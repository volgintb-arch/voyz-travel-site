# VOYZ Travel — сайт туров по Кыргызстану на внедорожниках

Статический сайт (HTML/CSS/JS), без сборки на сервере. 7 маршрутов на весь год, календарь сезонов,
фильтр в каталоге, форма заявки. Предпросмотр закрыт от поисковиков (`noindex`).

## Статус контента
- **Grand Expedition** — реальный маршрут VOYZ (по утверждённой программе).
- **Остальные 6 туров — концепты** (`data/tours_extra.json`, флаг `"concept": true`): маршруты придуманы на реальной
  географии Кыргызстана по образцу предложений конкурентов. Цены, даты, отзывы и контакты не придуманы.
  Перед запуском их нужно проверить: дороги и сезоны, разрешения для приграничных зон, ночёвки, безопасность.
- Для зимнего и весеннего туров на бесплатных стоках нет подходящих фото: использованы спутниковый снимок
  Copernicus и нейтральные кадры (см. `photo_note`). Нужны реальные сезонные фото.

## Мобильное приложение (iOS-стиль)
`app/` — отдельная мобильная версия: «жидкое стекло», крупные заголовки, нижняя панель вкладок, экран тура с раскрывающимися днями, шторка заявки, избранное, календарь по месяцам. С телефона сайт сам открывает `app/` (ссылка «Полная версия сайта» отключает переход). На компьютере `app/` показывается в рамке телефона. Собирается командой `python build_app.py` из тех же данных, что и сайт (запускать после `build_site.py`).

## Видео и анимации
- Видео из ваших стоков Pexels (`assets/video/`: 7 клипов, 720p, без звука, 6,4 МБ вместе, с постерами). Играют в шапках главной и нескольких туров и в ленте «В движении»; в режиме «уменьшить движение» отключаются.
- Движение: появление слов в заголовке, бегущая строка, счётчики, параллакс фото, прорисовка маршрута на карте, заполнение календаря, индикатор прокрутки.
- Секции чередуют светлый, белый, лаймовый и тёмный фон. Лайм используется для крупных заголовков и кнопок, мелкий текст на нём не ставится.

## Перед запуском
1. `assets/config.js` — куда отправлять заявки (`formEndpoint`: Formspree, вебхук Make/Zapier, свой бэкенд) и контакты
   (`telegram`, `whatsapp`, `phone`, `email`). Пустые значения скрыты, ничего не выдумано.
2. `privacy/` — политика конфиденциальности: краткая редакция, согласовать с юристом.
3. Цены: поле `price` в данных тура (сейчас `null`, цена не показывается).
4. В `build_site.py` переключить `NOINDEX = False`, когда сайт готов к индексации.
5. Права на фото Кок-Мойнока и Ак-Сай (из архива VOYZ) подтвердить. Авторы остальных фото: страница `credits/`
   (лицензии CC BY / CC BY-SA требуют указания авторства).

## Как добавить или изменить тур
Данные лежат в `data/tours.json` (флагман) и `data/tours_extra.json` (остальные туры). После правки:

```bash
python build_site.py
```

Скрипт пересоберёт все страницы (`index.html`, `tours/…`). Нужен Python 3 без внешних библиотек.
